# 系统设置：允许操作员修改密码开关设计

日期：2026-09-04  
状态：已确认，按方案 1 实施  
关联分支：与 `feature/review-export-filters` 同分支开发并一起上传

## 背景

操作员自助改密（顶栏「修改密码」+ `POST /api/auth/change-password`）已上线且默认可用。需要在「系统设置」增加全局开关，由管理员决定是否开放；默认与「允许操作员导出」一致为**禁止**。

## 需求结论

1. **入口：** 管理员「系统设置」增加开关「允许操作员修改密码」（允许 / 禁止），交互对齐现有「允许操作员导出数据」。
2. **默认：** `false`（禁止）；库中无该键时按禁止处理。
3. **关闭时：** 操作员端隐藏「修改密码」按钮；`change-password` 接口返回 403。
4. **开启时：** 行为与现有自助改密一致（校验规则不变）。
5. **标志下发：** 经 `/api/auth/me`（登录返回的 user 一并带上），字段名 `operator_change_password_enabled`（布尔）。
6. **时效：** 操作员进入布局时 `fetchMe` 刷新；管理员改配置后，操作员需刷新页面或重新进入布局后按钮才变。
7. **不受影响：** 管理员「用户管理 → 重置密码」不受此开关约束。

## 方案选择

| 方案 | 说明 | 结论 |
|------|------|------|
| 方案 1 | `system_config` 键 + 设置页开关 + 接口强制 + `/me` 下发 | **采用** |
| 方案 2 | 仅 `.env` 环境变量 | 无界面，不符需求 |
| 方案 3 | 用户表按人授权 | 本期为全局开关，过重 |

## 配置设计

- 键名：`operator_change_password_enabled`
- 取值：字符串 `'true'` / `'false'`（与 `operator_export_enabled` 一致）
- 初始化：`init-db` / `reset-keep-admin-rules` 路径中若不存在则插入 `'false'`
- 更新：现有 `PUT /api/config/<key>`（管理员）；操作日志 `update_config`；`log_display` 增加中文名「允许操作员修改密码」

## 接口设计

### `GET /api/auth/me`（及登录 `user`）

- 在用户基础字段之外增加：`operator_change_password_enabled: boolean`
- 读取 `SystemConfig`：值为 `'true'` 则为 `true`，否则 `false`
- 管理员调用时也可返回该字段（前端可忽略）

### `POST /api/auth/change-password`

- 在「必须是操作员」校验之后、业务校验之前：若配置非 `'true'` → **403**，提示「管理员未开放修改密码」
- 其余校验与成功路径不变

### 系统配置读写

- 无新接口；设置页读写同一键即可

## 前端设计

- `SettingsPage.vue`：增加第二项开关，绑定 `operator_change_password_enabled`
- `operator/Layout.vue`：`v-if` 控制「修改密码」按钮；`onMounted` 调用 `userStore.fetchMe()` 同步标志
- `user` store：`fetchMe` / `login` 已把返回写入 `user`；按钮读 `userStore.user?.operator_change_password_enabled`
- 管理员 Layout **不**增加改密入口（现状保持）

## 异常与边界

| 情况 | 处理 |
|------|------|
| 配置缺失 / 非 true | 视为禁止；改密 403；按钮不显示 |
| 开关关闭仍调 API | 403 |
| 开关开启 + 合法改密 | 200，行为同现网 |
| 管理员调改密 | 仍 403「请使用用户管理重置密码」（先于或并列于开关语义，保持现有文案） |
| 管理员重置密码 | 不受影响 |

## 测试要点

1. 默认 / 显式 false：操作员改密 → 403；`/me` 字段为 `false`
2. 设为 true：改密成功；`/me` 为 `true`
3. 设置页开关可读写并写操作日志
4. 管理员重置密码仍可用

## 验收标准

- 系统设置可见并可保存「允许操作员修改密码」，默认关
- 关：操作员无改密入口且接口拒绝
- 开：操作员可改密
- 管理员重置密码能力不变

## 非目标

- 不做忘记密码 / 邮箱找回
- 不强制改密后登出
- 不做按操作员单独授权
- 不在本期补齐「导出开关」的后端强制校验
- 不要求操作员端实时推送配置变更（刷新/`fetchMe` 即可）
