# 按导入批次删除数据设计

日期：2026-08-31  
状态：已确认，按方案 1 实施

## 背景

数据导入后会生成批次号，并写入待分类任务；审核通过后正式库也会记录来源批次。当前「数据导入」页仅支持上传、查看导入记录、下载错误报告，缺少按批次清理错误/重复导入数据的能力。

## 需求结论

1. **入口**：管理员「数据导入」→ 导入记录表格，每行提供「删除」。
2. **权限**：仅管理员（与现有导入接口一致）。
3. **确认**：点击后弹窗确认（展示批次号与将删除条数相关信息），确认后执行；无需输入批次号。
4. **删除范围（硬删除）**：
   - 该批次下所有任务草稿（`task_drafts`）
   - 挂在这些任务上的字段变更 / 分配 / 审核日志（外键依赖，必须一并删除）
   - 该批次下所有分类任务（`classification_tasks`）
   - 正式库中 `batch_id = 本批次` 的商品及其历史版本
   - 导入批次记录本身（`import_batches`）
   - 事务成功后尽力删除磁盘上的原始 Excel / 错误报告；文件删除失败不影响业务删除成功
5. **正式库覆盖规则**：若同一宝贝后来被其他批次再次审核覆盖（当前 `approved_products.batch_id` 已不是本批次），则**不删除**该正式库记录。
6. **保留**：通用操作日志（`operation_logs`）保留历史，并新增一条 `delete_import_batch` 记录便于追溯。

## 方案选择

| 方案 | 说明 | 结论 |
|------|------|------|
| 方案 1 | 导入列表内硬删除 + `DELETE /api/imports/{id}` | **采用** |
| 方案 2 | 软删除标记 | 改动大，不符合「清掉」诉求 |
| 方案 3 | 独立清理工具页 | 多余入口，日常不如列表内删除方便 |

## 接口设计

### `DELETE /api/imports/{batch_id}`

- 鉴权：`admin_required`
- 行为（同一数据库事务）：
  1. 加载批次；不存在 → 404
  2. 若 `status == processing` → 拒绝删除并提示稍后重试
  3. 收集该批次 `task_id` 列表；统计将删任务数、将删正式库数（`ApprovedProduct.batch_id == batch_id`）；在删前缓存 `file_path` / `error_report_path` / `batch_no`
  4. 按依赖顺序删除：草稿 → 字段变更日志 → 分配日志 → 审核日志 → 正式库历史（仅将被删正式库）→ 正式库（本批次）→ 分类任务 → 导入批次
  5. 写操作日志：`action=delete_import_batch`，`detail` 含 `batch_no`、任务数、正式库数等（写在同一事务内）
  6. 提交事务
  7. 尽力删除已缓存路径上的原始 Excel / 错误报告文件
- 成功响应字段：`batch_no`、`deleted_tasks`、`deleted_approved`（必返）；`kept_approved_overwritten` 可选

## 前端设计

- 文件：`frontend/src/views/admin/ImportList.vue`、`frontend/src/api/imports.js`
- 操作列增加「删除」（危险样式）；可与「错误报告」并排
- `ElMessageBox.confirm`：展示批次号 +「删除后不可恢复」说明；确认后调用删除 API（条数以接口返回为准，避免删前再打一次统计接口）
- 成功：提示「已删除任务 X 条、正式库 Y 条」并刷新列表；失败：沿用现有 request 错误提示

## 异常与边界

| 情况 | 处理 |
|------|------|
| 批次不存在 | 404 |
| 导入进行中 | 拒绝删除 |
| 非管理员 | 403 |
| DB 任一步失败 | 整笔回滚 |
| 磁盘文件删失败 | 仅记日志，接口仍成功 |

## 测试要点

1. 仅有任务、无正式库 → 删成功，批次消失  
2. 正式库仍指向本批次 → 正式库一并删除  
3. 正式库已被后续批次覆盖 → 正式库保留  
4. 非管理员 → 拒绝  
5. `processing` 状态 → 拒绝  

## 验收标准

- 管理员可在导入记录按批次删除  
- 确认后才真正删除  
- 该批次任务、任务侧日志、匹配正式库、批次记录均消失  
- 被其他批次覆盖的正式库商品仍在  
- 操作日志可见本次删除记录  

## 非目标

- 不做软删除 / 回收站 / 按批次号撤销恢复  
- 不改操作员端界面  
- 不批量多选删除（本期仅单批次）
