# 导入操作员列 + 批次筛选设计

日期：2026-07-27  
状态：已确认，按推荐方案实施

## 需求结论

1. Excel 列尾可选「操作员」；旧 19 列仍可导入。
2. 按登录用户名匹配启用中的操作员；成功则导入后状态为「待处理」并写入分配信息。
3. 空值 / 无列 → 未分发；匹配失败 / 停用 / 管理员账号 → 仍导入为未分发，错误报告写提醒。
4. 正式库增加 `batch_id`，审核通过时从任务写入；再次通过覆盖为最新批次。
5. 任务管理 / 审核中心 / 正式数据：批次多选筛选 + 列表显示批次号。

## 可能的改进

- 批次下拉目前取最近 500 条导入记录；批次极多时可改为按关键词搜索批次号。
- 正式库历史数据无 `batch_id`，需重新审核通过后才会带上批次。
