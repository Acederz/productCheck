# 分类多选字段改为 JSON 数组存储

日期：2026-10-21  
状态：已确认

## 问题

类别等字段用 `,` 拼接入库，与选项名内逗号（如「金,银丝交织包含海绵」）冲突。

## 方案

任务表 / 正式库下列改为 JSON 数组（与区隔一致）：  
`category_type`、`material_main`、`material_aux`、`packaging`、`size`、`roll_count`、`total_count`。

- 写入：一律数组  
- 读取旧逗号串：智能还原（整词命中规则选项则不拆；否则按逗号拆后再合并「连续片段能拼回已知选项」的部分）  
- `ensure_schema`：列迁移 + 数据转换  
- 导出仍用 `+` 拼接；大类仍单选字符串  

## Out

不改规则 Excel；不强制改选项文案。
